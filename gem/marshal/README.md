# Marshal

This package registers the Go-backed `Marshal` module as the lazy gem `marshal`. Import `github.com/oruby/oruby/gem/marshal` to register it and activate it with `mrb.Resolve("marshal")`; `gem/stdlib` includes the registration. The format implementation follows MRI Marshal 4.8 and the format behavior of [`take-cheeze/mruby-marshal`](https://github.com/take-cheeze/mruby-marshal) at commit `a15abaa0d4bcdede36d0ca6a589135e03779cac6`, ported to Go and ORuby APIs without C++ or Oniguruma.

The provider implements `Marshal.dump`, `Marshal.load` (with a proc and `freeze:`), `Marshal.restore`, and the `MAJOR_VERSION`/`MINOR_VERSION` constants. The writer and reader follow MRI's `marshal.c` (`w_object`, `r_object0`, `r_leave`): the same object table (floats and bignums take a slot), the `I` instance-variable wrapper with encodings (`E` / `encoding`), user subclasses (`C`), extended objects (`e`), `marshal_dump`/`marshal_load` (`U`), `_dump`/`_load` (`u`), `_load_data` (`d`), Struct and Data (`S`, filled without their own `initialize`), compare-by-identity Hashes, Rational and Complex, exceptions with `mesg`, `bt` and `cause`, and Time through its MRI-format `_dump`/`_load` (gem/time). Instance variables of Strings, Arrays, Hashes and Structs round trip (mruby keeps them in a side table). ruby/spec core/marshal passes except what needs encodings ORuby does not keep: a Symbol's encoding (a Symbol is its bytes here), a Regexp's (ASCII sources are US-ASCII), and Random's MRI Mersenne Twister state.

**Never use `Marshal.load` with untrusted data.** Loading resolves named constants, allocates objects and invokes custom hooks (`_load`, `marshal_load`, `_load_data`). Those actions can execute arbitrary Ruby code. Size limits are not a security sandbox and do not make untrusted Marshal data safe.
